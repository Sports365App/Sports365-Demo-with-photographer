# sports365-demo

Practice repository for learning GitHub before the real Sports365 code is transferred in.

This is a clickable demo built from Brian's design mockups. It is plain HTML and CSS, with no real accounts, payments or messages behind it.

## Pages

| File | What it shows |
|---|---|
| `index.html` | Home page for coaches, trainers and organizations |
| `dashboard.html` | Coach home dashboard (logged in) |
| `book.html` | Public coach booking page that parents use |
| `styles.css` | Shared colors, fonts and buttons |
| `assets/logo.svg` | Sports365 logo |

## Try it

Download the repo (Code → Download ZIP), unzip it, and open `index.html` in a browser.
